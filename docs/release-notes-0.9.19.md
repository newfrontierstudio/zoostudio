ZOOstudio 0.9.19 プレビュー版です。

## 受信方式
- 受信方式の既定を「Studioで直接受信」に変更しました。新規に受信設定を作成すると、対応チューナー（32bit BonDriver_PXMLT5PE）では直接受信が選ばれます。既存の受信設定はそのまま引き継がれます。
- 「TVTestを使う」は TVTest 互換方式で、TVTest.exe と BonDriver の登録ペアで受信します。「Studioで直接受信」は、Studio の専用受信エンジンが BonDriver を直接駆動し、番組表も自前で取得します。TVTest 本体は使用しません。共通するのは、BonDriver 経由でチューナーを駆動する点のみです。

## インストーラー
- インストーラーが重複する .NET ランタイムを含まないよう修正しました（0.9.18 の修正を含みます）。

既存の予約・設定は引き継がれます。更新前に録画・番組表取得を終え、通知領域の Studio から完全終了してください。
