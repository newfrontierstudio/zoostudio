ZOOstudio 0.9.20 安定版です。機能は 0.9.19 と同じです。

## インストーラー
- 0.9.19 のインストーラーは、.NET ランタイムの一部ファイル（hostfxr.dll など）を「重複」と判断して同梱していませんでしたが、実際には起動に必要なファイルでした。環境によっては、インストール後に ZOOstudio が起動しない問題がありました。
- 0.9.20 ではパッケージの全ファイルを同梱しました。空のフォルダへのインストールと、本体・録画ワーカーの起動を確認しています。
- 0.9.19 が起動しない場合は、0.9.20 を上書きインストールしてください。

既存の予約・設定は引き継がれます。更新前に録画・番組表取得を終え、通知領域の Studio から完全終了してください。
