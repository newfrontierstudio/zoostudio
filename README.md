# ZOOstudio 0.5.1 — 録画の安定性改善・Inferno更新

録画終了時の後片付けを見直し、次の録画へスムーズに移れるよう改善しました。途中取り消しや、続けて録画する動作も確認しています。

付属の動画編集アプリ「Inferno」を0.6.1へ更新しました。

- 映像クリックで再生／一時停止
- 試聴用ピークメーター・音量・ミュートを追加
- マウス操作の軌跡を表示。色・太さ・透明度を設定可能
- 一覧表示を整理

試聴の音量設定は、書き出す動画には影響しません。Studio付属のInfernoは、.NETの追加インストールなしで利用できます。

引き続きプレビュー版として、安定性と使いやすさを改善していきます。

[インストーラーをダウンロード](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.5.1)

## 更新・受信方式の切替

録画・番組表取得の終了を待ち、通知領域のStudioから完全終了して更新してください。

現在の受信方式は自動変更しません。詳細設定 → 受信設定 → 受信方式から切り替えられます。

[動作条件・検証範囲](VALIDATION.md)に詳しい案内があります。

## 配布について

Studio本体のソースは非公開です。このリポジトリには案内と文書を置き、実行ファイルはReleasesで配布します。GitHubが自動表示する「Source code」のアーカイブにも、このリポジトリの文書のみが含まれます。

第三者コンポーネントのライセンス・著作権表示は同梱しています。
