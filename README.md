# ZOOstudio 0.9.20（安定版）

## 配布更新（2026-11-22）
- 受信方式の既定を「Studioで直接受信」に変更しました。
- インストーラーが重複する.NETランタイムを含まないよう修正しました。
- 0.9.20の配布です。既存の予約・設定を引き継いで上書き更新できます。

番組表・予約・録画を管理するWindows向けアプリです。TVTest・BonDriverの環境を活用できます。

[最新版をダウンロード](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.9.20)

## Satlite
- 自動おすすめの「👍 次のおすすめに活かす」を、おすすめ評価に反映します。自動検索予約は👍の対象外です。
- 時間軸カーブは試作段階で、実用機能としては提供していません。
- 自動検索予約の並び順を、おすすめの優先順位に反映します。
- Wikiの関連語を参照し、地名や人物などのつながりから候補を広げます。
- 自動おすすめを「録画しない」にした系列は再提示を抑え、同じ系列を手動予約すると解除します。

## 検索条件・保存先
- 検索ワード一覧の追加ボタン名を「新規追加」に変更しました。曖昧検索は追加していません。
- Studioで表示する検索条件を基準にし、ジャンルなどの過去設定や非表示条件は使いません。
- 番組詳細が後から届いた場合、同じ番組の仮登録内容を更新して重複を抑えます。
- 保存先の空き容量とTS録画時間の目安を表示し、別ドライブやフォルダーを選べます。

## 量子認知・Rust
- 量子認知v3（Chaos）を導入し、履歴に基づく評価パラメーターの調整を更新しました。
- C#とRustの並行照合に対応しました。今回の配布ではC#の結果を使用し、Rustとの差分を記録します。

## 予約・録画
- 放送途中に予約した番組が、番組表で予約済み・録画中と表示されない問題を修正しました。
- 予約後の重複した読み出しを減らし、画面の応答を改善しました。
- 録画用TVTestを通知領域に格納します。
- 録画対象サービスの抽出を見直し、ワンセグを除外します。字幕は初期値OFFです。

## 受信方式
- 「TVTestを使う」は TVTest 互換方式です。TVTest.exe と BonDriver の登録ペアで受信します。
- 「Studioで直接受信」は、Studio の専用受信エンジンが BonDriver を直接駆動し、番組表も自前で取得します。TVTest 本体は使用しません。
- 共通するのは、BonDriver 経由でチューナーを駆動する点のみです。

既存の予約・設定は引き継がれます。更新前に録画・番組表取得を終え、通知領域のStudioから完全終了してください。

Windows 10以降のx64用インストーラーです。.NET 8を同梱します。TVTest・BonDriverなどの受信環境は別途必要です。

実機での長時間録画・各局の継続検証は進行中です。確認範囲は [VALIDATION.md](https://github.com/newfrontierstudio/zoostudio/blob/main/VALIDATION.md) に記載しています。
