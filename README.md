# ZOOstudio 0.6.3 — 自動予約・録画ファイル名を改善

Studio単独で予約・録画・番組表を管理できます。

インテリジェント自動おすすめ予約：視聴済みや取り消した放送を考慮し、重複を避けて録画候補を選びます。ユーザーの手動予約を優先します。

録画ファイル名の放送記号の整理と、自動予約の再登録防止を改善しました。録画済み一覧で「視聴済み」を指定すると、同じ回を判別できる場合は自動予約の候補から除外します。

手動予約は優先します。既存の録画ファイルは変更しません。Inferno 0.8.2を同梱しています。

[インストーラーをダウンロード](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.6.3)

## 更新・受信方式の切替

録画・番組表取得の終了を待ち、通知領域のStudioから完全終了して更新してください。

現在の受信方式は自動変更しません。詳細設定 → 受信設定 → 受信方式から切り替えられます。

[動作条件・検証範囲](VALIDATION.md)に詳しい案内があります。

## 配布について

Studio本体のソースは非公開です。このリポジトリには案内と文書を置き、実行ファイルはReleasesで配布します。GitHubが自動表示する「Source code」のアーカイブにも、このリポジトリの文書のみが含まれます。

第三者コンポーネントのライセンス・著作権表示は同梱しています。
