# ZOOstudio 0.5 — スタンドアローン録画に対応

対応環境では、TVTest・TVRockを起動せず、Studioだけで予約録画と番組表の取得ができるようになりました。

- 予約に合わせてPCをスリープから復帰させる設定を追加しました。
- 復帰の準備時間を、分・秒で指定できます。
- 詳細設定を項目ごとに整理しました。
- 録画中でも取り消せます。途中までの録画ファイルは残ります。

今版はプレビュー版です。引き続き安定性を改善していきます。

[インストーラーをダウンロード](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.5)

## 更新・受信方式の切替

録画・番組表取得の終了を待ち、通知領域のStudioから完全終了して更新してください。

現在の受信方式は自動変更しません。詳細設定 → 受信設定 → 受信方式から切り替えられます。

[動作条件・検証範囲](VALIDATION.md)に詳しい案内があります。

## 配布について

Studio本体のソースは非公開です。このリポジトリには案内と文書を置き、実行ファイルはReleasesで配布します。GitHubが自動表示する「Source code」のアーカイブにも、このリポジトリの文書のみが含まれます。

第三者コンポーネントのライセンス・著作権表示は同梱しています。
