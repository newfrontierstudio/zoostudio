# ZOOstudio Pre 0.13.29

**無料・人柱版です。正式ローンチ版は有料化予定です。**

**TVRockのリプレイスを目指す予約・番組表・録画管理アプリです。** 予約の保存と録画時刻の管理はStudio、受信・録画は設定済みのTVTest・BonDriverが担当します。予約録画の実行にTVRock本体は不要です。

[**インストーラーをダウンロード**](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.13.29)

**Zooと同じ操作画面で、Studioの録画予約を管理できます。** TVRockに登録済みの録画予約は、起動時・更新時に重複と競合を確認して自動で取り込みます。

## 今回の更新

- EPG取得中の局を予約一覧に「EPG取得中（番組表）」として、録画中と同じ薄赤で表示。取得終了・中断後は消え、録画予約の件数には含めません。マウスを重ねると使用チューナーを表示します。
- 取得用TVTestに局ロゴデータを引き継ぎ、タスクバーで局アイコンを使う設定に変更。ロゴファイルと設定は確認済みですが、タスクバーでの実表示は確認継続中です。

これまでの主な更新：

- Studio単独で放送波から番組表を取得。F5・「最新の情報」と定期取得に対応し、ニュースは通常より短い間隔で更新します。
- 録画と番組表取得でチューナーの使用権を共通管理。録画を優先し、EPG取得は空きチューナーを使用、使用中なら別候補を確認します。録画の準備時にはEPG取得側が明け渡します。
- 別チューナーのTVTest起動途中を競合と誤認し、進行中の録画を中断する不具合を修正しました。
- 更新・検索条件の候補計算をバックグラウンド化し、更新中も画面を操作できるよう改善しました。
- 詳細設定に録画準備時間と「指定時間未満は録画しない」のON/OFF・分秒設定を追加。変更は自動保存します。短い番組は「録画しない」に残し、マウスを重ねると理由を表示します。
- 予約のポップアップに検索ワードを表示。旧取り込み予約の検索条件も照合し、理由や検索ワードを先頭に表示します。

0.13.22から引き継ぐ主な変更：

- Zooと戻る・進む・更新、ジェスチャ設定、再放送のおすすめ判定のソースを共通化。
- F5と「最新の情報」ボタンで更新し、更新時刻を表示。内蔵ジェスチャは初期OFFで、左右・上下の動作を詳細設定から変更できます。
- TVRock予約を起動時・更新時に自動取り込み。既存・取り消し済みの予約や競合を確認して追加します。
- 検索条件を1分ごとに確認して自動予約。認識済み放送局の選択、個別のNGワード欄、時・分セレクタに対応しました。NGワードは欄ごとに扱い、全角・半角の空白を無視します。
- 自動おすすめ予約は起動時ON。再放送は控え、好みとの一致が強い場合は候補に残します。
- 設定保存の初期フォルダーはインストール先、既定ファイル名には日時を分まで含めます。
- 録画用TVTestへ局ロゴデータを引き継ぎます。空のファイル名予約マーカーは録画先とは別の内部フォルダーで管理し、終了時に削除します。
- 右クリック操作を妨げるトレイ通知を撤去しました。

2週間を標準とする表示、予約理由からのフィルター編集、録画先の詳細設定欄への追加は今回含みません。録画中のファイル名変更は行いません。

## 今できること

- TVTest・BonDriver・局設定の取り込み、1局ずつの受信・短時間録画確認。
- TVRockの登録済み録画予約を、対象・録画先・競合を確認してStudioへ取り込み。
- Zooの予約一覧で、待機中の予約編集、○／×による有効・無効の切り替え、録画開始・終了の秒数補正。
- 放送波からの番組表取得、保存済み番組表の表示・検索、選択した番組のStudioへの予約。
- ChatGPTタブで、取り込んだ好み条件による保存済み番組表の絞り込み。
- Studioによるチューナー割り当て、予約保存、録画開始・終了の管理。
- 通知領域での予約待機と録画本数のアイコン表示。
- 画面の位置・大きさ、局の表示設定の保存。

**スリープ復帰・Windows起動時の自動起動は未対応です。** キーワード条件による自動予約は、起動中かつ自動おすすめ予約ONの間、1分ごとに確認します。ジャンルなど未対応の条件は自動実行せず、要確認として表示します。

初期の番組表はZooの保存済みデータを利用できます。設定済みTVTest・BonDriverと同梱のEPG取得プラグインで、TVRockを起動せずに新しい番組表を取得します。通常は60分、放送が近いニュースは15分を目安に確認します。録画開始が近い場合や全チューナーが使用中の場合は待機し、取得0件・失敗時は保存済み情報を保持して再試行します。おすすめ予約には6時間以内に取得した番組表が必要です。

最短録画時間は番組そのものの長さで判定し、開始・終了の秒数補正を含めません。手動・条件・おすすめ・取り込み予約より優先しますが、進行中の録画には適用しません。設定をOFFに戻すと、この設定だけで無効になった未来の予約を戻します。ユーザーが無効にした予約は戻しません。

## はじめ方

1. インストーラーを実行し、Studioを開きます。以前のStudioで保存した受信設定・予約は引き継ぎます。
2. 未設定の場合は、画面上部の手順に沿って放送局・チューナーを設定します。設定済みなら予約の取り込みへ進みます。
3. 「TVRockの予約を確認して取り込む」で一覧を開き、Studioの録画先と取り込む予約を確認して登録します。取り込まない場合は、そのまま完了できます。
4. 「完了してStudioを起動」でZooと共通の操作画面へ進みます。待機中の予約はダブルクリックで編集できます。
5. **StudioとPCを起動して待機してください。** スリープ・Studio完全終了中は新しい予約を開始できません。

×は通知領域への格納です。アイコンのダブルクリックで画面を開き、右クリックメニューで完全終了できます。

## 予約の取り込み

局・番組名・録画日時・開始／終了の秒数補正を取り込みます。検索予約は現在登録済みの放送回を、Studioの日時指定予約として取り込みます。

起動時・更新時に、重複や競合を確認して未取り込みの予約を自動で追加します。一覧で確認して取り込むこともできます。**元のTVRock予約・設定は変更せず、同じ予約を重複して取り込みません。既存予約の変更を同期する機能ではありません。** 取り込み後のTVRock側の変更はStudioに反映しません。録画先は取り込み画面で指定したStudioの保存先を使います。

終了済み・録画中・開始直前・繰り返し・視聴専用・番組情報取得用・別PC用・ワンセグなど、対象外の予約は理由を表示します。局を照合できない予約や、チューナー不足がある選択も登録前に確認します。

検索条件・番組追従・電源操作・終了後処理・TVRockの保存先やファイル名書式は引き継ぎません。

## TVRockと同居できますか？

別の場所にインストールし、元のTVRock・TVTest・Zooの設定・予約を上書きしません。

ただし、**受信確認やStudioでの録画運用に切り替える際は、TVRock本体を終了してください。** TVRockで録画中なら終了を待ってください。TVRock起動中や、チューナーが使用中・状態不明の場合はStudio側の録画を開始しません。Studioの録画中にTVRockが起動した場合も、競合を避けるためStudio側の録画を終了します。

## 必要な環境

- Windows 10/11・64ビット。.NET同梱。
- 設定済みのTVTest、BonDriver、局設定。
- **現在はCasProcessor設定済みTVTest環境が対象です。** 全構成への対応は未検証です。

TVRock本体・TVRock Zooは取り込み後の予約録画の実行には不要です。TVTest・BonDriver・受信処理プラグイン・放送録画は同梱しません。TSTask・RecTask専用構成はこのPreの対象外です。

## アンインストール

1. 録画の終了を待ち、通知領域の右クリックメニューからアプリを完全終了します。
2. Windowsの「設定 → アプリ」で製品名を選んでアンインストールするか、スタートメニューの「アンインストール」を実行します。

アプリ本体とショートカットを削除します。**録画ファイル・予約・設定は残ります。TVRock・TVTestおよび他のアプリは削除しません。** 保存先をアプリのフォルダー内にした場合も、利用者が作成したファイルは削除対象に追加しません。

再インストール時に保存済みの設定を利用できます。データを消す操作はアンインストールに含めていません。

## 診断ログ

詳細設定の「診断ログ ON／OFF」で追加の診断ログを切り替えます。初期状態はOFFで、選択は保存されます。OFFでもエラーの概要と録画結果は残し、既存のログは削除しません。

追加の診断ログは通信の成否・所要時間や予約保存などを記録します。番組名・接続先URL・個人のパス・応答本文・例外のメッセージは記録せず、自動送信もしません。ログは1ファイル約1MBを上限に前回分へ切り替えます。
保存先：`%LOCALAPPDATA%\ZOOstudioPre\zoo-ui` の `diagnostic.jsonl` と `errors.jsonl`。

## 録画しない予約の取り込み

TVRockで無効になっている予約は、Studioでも「録画しない」のまま取り込みます。チューナーを占有せず、自動で録画を開始しません。×を押して明示的に有効化した場合にだけ予約待機へ戻り、その際に競合を確認します。

以前取り込んだ同じTVRockから取りこぼしていた無効予約は、受信局と日時を照合できるものを補完します。取り込み元を選んだことがない環境からは自動で取り込みません。既存のStudio予約は上書きせず、元のTVRock予約も変更しません。対象外の繰り返し・特殊予約などは引き続き除外します。

## 非公開の不具合報告

「詳細設定」または「HELP」の「不具合を報告」から、アカウント登録なしで送信できます。製品・バージョンと直近の診断ログを自動でまとめ、送信前に内容を確認できます。

**診断ログの送信 ON／OFF** を表示します。OFFでは本文だけを送信します。ログには番組名・予約一覧・録画履歴・個人のパスを含めません。本文には番組名など、知られたくない情報は書かないでください。診断ログの記録自体のON／OFFとは別の設定です。報告本文と送信ONにした診断ログは開発者へメールで届きます。報告は非公開で保存し、受付番号を表示します。

[不具合報告フォーム](https://zoo-support-report.stonyray64.chatgpt.site/)も利用できます。フォーム単独ではアプリのログを自動取得しません。送信結果が不明の場合は、自動再送しません。

診断ログ・エラーログには、記録時の製品名とバージョンを自動で残します。アプリから報告する際も製品名・バージョンを自動取得するため、利用者が調べて入力する必要はありません。診断ログOFFでも、保持するエラー概要にはこれらを記録します。以前のログに後からバージョンを付けることはありません。

報告の受け付けはメール通知から分離しています。診断ログの送信ON／OFFと内容確認は従来通りです。開発者用受信箱はサイト所有者のログインが必要で、一般の報告者にはログインは不要です。
