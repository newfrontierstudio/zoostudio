# ZOOstudio 0.6.26（プレビュー版）

Studio単独で予約・録画・番組表を管理できます。

インテリジェント自動おすすめ予約は、録画履歴や取り消した番組などを参考に候補を選び、ユーザーの手動予約を優先します。詳細設定で件数を変更でき、「上限なし」も選べます。

ローカル局名の保存・復元を修正し、上部のボタンと案内表示を整理しました。

[インストーラーをダウンロード](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.6.26)

更新前にStudioを完全終了してください。

## 配布について

アプリ本体のソースは非公開です。このリポジトリでは案内とダウンロードを提供します。GitHubの「Source code」には、このリポジトリの文書のみが含まれます。
