# ZOOstudio 0.13.44

**TVRockに代わって予約録画する、無料の開発版です。** 予約と時刻の管理はStudio、受信・録画は設定済みのTVTest・BonDriverが担当します。録画の実行にTVRock本体は不要です。正式版の料金・提供方式は検討中です。

[**インストーラーをダウンロード**](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.13.44)

## 今回の更新

- 詳細設定に「TVRockへ予約を引き継いで戻す」を追加。今後の予約を確認し、対応できる予約の追加・変更・無効化を反映します。元ファイルをバックアップしてから実行し、Studioの自動起動をOFFにして終了します。
- 移せない予約は理由付きで一覧表示。TVRock側でも変更された予約を自動で上書きせず、二重登録やチューナーの重なりを確認します。
- プレビューをファイルのピクセル比率・表示比率に合わせました。1440×1080で表示比率16:9の映像も正しい比率で表示します。
- 再生「▶」・停止「■」を同じ大きさにし、映像の準備ができるまでサムネイルを残します。自動再生テストは消音にしました。
- AV1変換中はファイル右側に変換位置・処理経過・残り時間、最下部に全体の進捗・経過・残り時間・終了予測を表示します。残り時間は処理速度からの推定です。
- アプリ画面とショートカットの名称を「ZOOstudio」に統一しました。既存の予約・設定を使うため、内部の保存フォルダー名は変更しません。

## 録画済みの表示・再生

RecフォルダーのTS・MP4を、幅320pxのプレビュー付きで縦に表示します。日付・名前・サイズ、昇順・降順を選択でき、初期値は日付の新しい順です。タブ内で再生・一時停止・停止・シーク・音量を操作できます。

## AV1で画質と容量を両立

**AV1は、高い圧縮効率で、画質を保ちながらファイル容量を抑えやすい先進的な動画圧縮方式です。** 録画を省スペースで保存したい場合に使えます。AV1の設計については[AOMediaの公式説明](https://aomedia.org/specifications/)も参照してください。

「録画済み」でTSを複数選択し、ビットレートを一括指定して「MP4（AV1）バッチ変換」を開始します。指示したファイルを1本ずつ変換します。自動変換は行いません。

- **保存形式はMP4、中の映像がAV1です。** AVC・HEVCへの変換は行いません。
- 元の解像度・FPS・表示比率を維持します。インターレースは同じFPSでプログレッシブ化します。
- ビットレートを下げると容量を抑えられますが、画質との兼ね合いがあります。効果は映像・設定・エンコーダーによって変わり、無劣化や一定の削減率を保証するものではありません。
- **元TSは残します。** 音声はAACに変換し、放送字幕・データ放送はMP4へ移しません。
- 対応GPUのNVIDIA NVENC・AMD AMF・Intel QSV、またはCPUで変換します。実行可能なGPUエンコーダーだけを選択肢に表示し、Blackwell検出時は「NVENC BLACKWELL」と表示します。
- CPU・RTX 5060でのAV1変換を確認しています。AMD/Intel実機での変換は未検証です。
- FFmpeg・FFprobe・mpvを同梱しているため、これらの追加インストールは不要です。インストーラーは約170MBです。

再生側にもAV1対応が必要です。変換中のファイルや録画中のファイルは変換対象にしません。既存ファイルは上書きせず、中止時は作成途中のMP4を除去します。

## はじめ方

1. インストーラーを実行し、Studioを開きます。以前のStudioで保存した受信設定・予約は引き継ぎます。
2. 未設定の場合は、放送局・チューナーを設定します。設定済みなら予約の取り込みへ進みます。
3. 「TVRockの予約を確認して取り込む」で一覧を開き、Studioの録画先と取り込む予約を確認します。起動時・更新時の自動取り込みもあります。
4. **TVRock本体を終了してから、Studioでの録画運用に切り替えてください。** 同じチューナーを両方で同時に使わないでください。
5. StudioとPCを起動して待機してください。スリープ・Studio完全終了中は新しい予約を開始できません。

×は通知領域への格納です。アイコンの右クリックから完全終了できます。Windows起動時の自動起動・通知領域への格納は詳細設定からON/OFFでき、初期値ON、変更は自動保存です。スリープ復帰は未対応です。

## TVRockへ戻すには

**アンインストールする前に、詳細設定の「TVRockへ予約を引き継いで戻す」を使ってください。**

1. 録画・動画変換の終了を待ち、TVRock本体は終了した状態でボタンを押します。
2. 「追加」「変更」「登録済み」「要確認」の一覧を確認します。「要確認」がある場合は、TVRockで手動調整することを確認してから実行します。
3. バックアップ後、対応できる予約をTVRockへ反映します。Studioの自動起動をOFFにし、Studioを終了します。
4. 元のTVRockを起動して予約と録画先を確認してください。必要ならその後Studioをアンインストールできます。

日時・局・番組名・開始/終了補正のある今後の予約を対象にします。Studioで取り消した元のTVRock予約は、照合できる場合に無効化します。Studioで無効にしただけの新規予約は追加しません。録画先・ファイル名はTVRock側の設定を使います。

元のTVRock予約に記録された局・チューナー情報とdtv.iniを照合します。該当局の履歴がない場合、チューナーを確定できない場合、予約が重なる場合などは「要確認」に残します。別途TVRockで編集された予約、放送局を変更した予約、繰り返し・視聴専用などの特殊予約は自動で変更しません。

**検索条件・おすすめ設定・Studio固有の最短録画時間やファイル名設定などはTVRockへ移しません。** 現在登録済みの各放送回を移す機能で、今後の自動予約条件の変換ではありません。複数のTVRock環境がある場合は戻すフォルダーを選びます。

バックアップは設定フォルダー内の `tvrock-return-backups` に保存します。引き継ぎ後にStudioを開いた場合は、TVRock運用中であることを案内します。Studioで録画を再開する場合はTVRockを終了し、再開の確認をしてください。

## 予約・番組表の機能

- 待機中の予約編集、録画する/しないの切り替え、開始・終了の秒数補正。
- 通常各局6時間ごとのEPG取得。録画優先で空きチューナーを使用し、使用中なら待機します。WBSの予約がある場合だけ、開始60～15分前に取得成功を1回確認します。
- F5・「最新の情報」で更新。更新・検索の計算をバックグラウンド化しています。
- 検索条件による自動予約、個別NGワード、空白を無視した語句検索、検索根拠の表示。
- 録画準備時間、指定時間未満は録画しない設定、理由のマウスオーバー表示。
- 録画ごとの局アイコンと、右クリックからその録画だけの終了。

TVRockからの通常取り込みは元の予約を書き換えません。**上記の「TVRockへ戻す」を明示的に実行した場合に限り、確認した変更を書き込みます。** 通常の取り込みは変更を双方向同期する機能ではありません。

## 必要な環境と確認範囲

Windows 10/11・64bit、設定済みのTVTest・BonDriver・局設定が必要です。.NETは同梱します。現在はCasProcessor設定済みTVTest環境が対象です。TVTest・BonDriver・カード関連設定・録画ファイルは配布物に含みません。

32bit/64bit版TVTestの部品配置に対応しますが、ビット数の自動移行は行いません。64bit構成は短尺試験で成功した一方、実運用でカード接続エラーが再発しています。元の32bit環境を残し、使用する構成で受信・復号を確認してください。

引き継ぎは合成予約ファイルで追加・変更・重複防止・失敗時の復元を検証しています。実運用TVRockへの書き込みと、全バージョン・全構成での網羅的な確認は未実施です。[詳しい検証範囲](VALIDATION.md)を参照してください。

## 保存先・アンインストール

- アプリ：初期値 `%LOCALAPPDATA%\Programs\ZOOstudioPre`
- 予約・設定・ログ：`%LOCALAPPDATA%\ZOOstudioPre`
- 通常の録画：Studioで指定したRecフォルダー

録画・変換の終了を待ち、通知領域のメニューからStudioを完全終了して、Windowsの「設定 → アプリ」からアンインストールしてください。アプリ本体とショートカットを削除し、録画ファイル・予約・設定、TVRock・TVTest・Zooは残します。**アンインストール単独では予約をTVRockへ移しません。** 上記の引き継ぎを先に実行してください。
