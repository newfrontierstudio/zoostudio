# ZOOstudio 0.8.1（プレビュー版）

番組表・予約・録画を管理するWindows向けアプリです。TVTest・BonDriverの環境を活用できます。

[最新版をダウンロード](https://github.com/newfrontierstudio/zoostudio/releases/latest)

## 0.8.1

おすすめの評価に、番組内容、時間帯、予約・取消・予約枠の履歴を反映します。表示・予約・取消などの操作も、次の候補選びに反映されます。

おすすめ詳細では、評価経路、位相差、干渉量、通常評価との差を確認できます。量子認知 v2 は、ファインマンの経路積分と量子力学の観測・重ね合わせ・干渉を参考にした計算モデルです。量子コンピューターは使用しません。

更新前に録画と番組表取得を終え、ZOOstudioを完全終了してください。既存の予約・設定は引き継がれます。
