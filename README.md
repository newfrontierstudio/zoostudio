# ZOOstudio Pre 0.9.0

**無料・人柱版です。正式ローンチ版は有料化を予定しています。**

**ZOOstudioは、TVRockのリプレイスを目指して開発している次世代の予約・番組表・録画管理アプリです。** BonDriverとTVTestを活かし、TVRockが担っている予約管理・番組表・チューナー割り当てをStudioへ移す計画です。受信・録画はTVTestが担当します。

**今回のPre 0.9.0で使えるのは、既存設定の取り込み・受信確認・既存Zooの起動までです。** 独立した予約管理・番組表は開発中です。今すぐTVRockをアンインストールして置き換える版ではありません。

[インストーラーをダウンロード](https://github.com/newfrontierstudio/zoostudio/releases)

## TVRockと同居できますか？

**はい。TVRock・TVTest・既存Zooと別の場所にインストールします。既存の設定・予約・録画ファイルは上書きしません。**

受信確認では同じ物理チューナーを使います。使用中・予約直前のチューナーを避け、確認中も予約との競合を監視します。ただし、全機種・全録画構成で競合が起きないことを保証する版ではありません。大事な録画の直前は試験を避けてください。

## 必要な環境

- Windows 10/11・64ビット。.NET実行環境は同梱。
- 動作するよう設定済みのTVRockとTVTest、BonDriver・局設定。
- コントロール画面として使う [TVRock Zoo](https://github.com/newfrontierstudio/tvrock-zoo/releases)。別途インストールしてください。
- 実際の録画確認は、TVRockに登録されたTVTest用チューナー設定が対象です。

TVRock本体・TVTest・BonDriver・受信処理プラグイン・放送の録画は配布物に含みません。

## 使い方

1. TVRockを起動し、必要なら普段使うTVTestも一度起動してから、ZOOstudio Preを開きます。
2. 自動検出した局の「使用」を選び、「② 1局ずつ5秒確認」で受信・録画を確認します。選局後8秒待ち、約5秒録画して次の局へ進みます。
3. 「③ 保存してZooを起動」で、Zooの予約一覧・番組表へ進みます。

設定済みの場合、通常起動はZooへ直接進みます。スタートメニューの「ZOOstudio Pre 受信設定」で設定を開き直せます。

「確認用録画」ではファイルを選択・ダブルクリックして既定の動画プレーヤーへ渡します。映像・音声は自分でも確認してください。「映像OK」はフレームの取り出しを確認した意味で、録画全体の品質保証ではありません。

## 制限・検証状況

- 新規のBonDriver導入・全周波数スキャン・地域コードの自動設定は未実装です。現段階は既存設定の取り込みです。
- 開発環境のPXMLT5PEとTVTestで実録画の試作を行いました。他機種・BS/CS・録画サーバー構成を網羅した検証はできていません。
- TSTask・RecTask専用構成の受信確認は、このPreの対応範囲ではありません。既存Zoo側の対応とは別です。
- テスト用TVTestを別の場所へコピーし、既存の受信処理プラグインを限定して読み込みます。構成によっては録画確認できません。
- 実行ファイルは未署名です。

## 保存先とアンインストール

- アプリ：`%LOCALAPPDATA%\Programs\ZOOstudioPre`
- 設定・ログ・確認用録画：`%LOCALAPPDATA%\ZOOstudioPre`

アンインストールではTVRock・TVTest・Zooを削除しません。設定・確認用録画も自動削除しません。

## TVRockリプレイスへの開発段階

- 今回のPre：既存の受信設定を取り込み、TVTestで受信・録画を確認。既存Zooの操作画面へ接続。
- 次の段階：Studio自身による予約の保存・実行、番組表、空きチューナーの割り当てを実装。
- 目標：設定・予約・録画運用をStudioで完結させ、TVRockへの依存を解消。

未実装部分は予定であり、完成時期を約束するものではありません。
