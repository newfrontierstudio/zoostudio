# ZOOstudio Pre 0.10.2

**無料・人柱版です。正式ローンチ版は有料化予定です。**

**TVRockのリプレイスを目指す予約・番組表・録画管理アプリです。** 受信・録画は既存のTVTest・BonDriverが担当します。

**0.10.0からTVRockを起動せずに、日時指定の予約録画ができます。** Studio自身が予約を保存し、時刻に合わせてTVTestの起動・録画開始・終了を管理します。既存Zooを開く方式からStudio自身の予約画面へ変更しました。

[**インストーラーをダウンロード**](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.10.2-pre.1)

0.10.2では、選択中のタブをZooと同じ淡い青紫に調整しました。

## 今できること

- TVTest・BonDriver・局設定の取り込みと、1局ずつの受信・短時間録画確認。
- 局・番組名・開始／終了日時・保存先を指定した予約録画。
- チューナー割り当て、重複予約のチェック、取り消し・録画中止・再生。
- ×で通知領域に格納して予約待機。録画中は赤地・白文字で録画本数を表示し、完了で通常アイコンへ戻ります。
- 通知領域のアイコンにマウスを重ねると、録画中の局名・番組名・終了予定を一覧表示。タスクバーのプレビューにも録画情報を設定します。
- ウィンドウの位置・大きさの保存。

**番組表・キーワード予約・スリープ復帰・Windows起動時の自動起動・TVRockに登録済みの録画予約の引き継ぎは未対応です。** 日時指定予約の試作で、長時間・複数局の無人運用まで検証できた版ではありません。

## TVRockと同居できますか？

別の場所にインストールし、元のTVRock・TVTest・Zooの設定・予約は上書きしません。

ただし、**この版の受信確認・独立予約録画はTVRock本体を終了してから使ってください。** TVRockが起動中の場合は録画を開始しません。Studioの録画中にTVRockが起動した場合も、競合を避けるためStudio側の録画を終了します。

TVRockで録画中なら終了を待って切り替えてください。**受信設定（局・チューナー）は引き継げます。TVRockに登録済みの録画予約は引き継ぎません。**他のアプリで使用中・状態不明のチューナーも使いません。

## 必要な環境

- Windows 10/11・64ビット。.NET同梱。
- 設定済みのTVTest、BonDriver、局設定。
- **現在の録画試作はCasProcessor設定済みTVTest環境が対象です。** 全構成に対応する受信処理の取り込みは未検証です。
- TVRock本体・TVRock Zooは、日時指定予約の実行には不要です。

TVTest・BonDriver・受信処理プラグイン・放送録画は同梱しません。TSTask・RecTask専用構成はこのPreの対象外です。

## 使い方

1. インストーラーを実行しStudioを開きます。Studio 0.9.0で保存した受信設定を引き継ぎます。
2. 未設定の場合はTVTestを起動して検出させるか、「TVTestの場所を選ぶ」から取り込みます。使う局を選び、必要に応じて「② 1局ずつ5秒確認」で確認します。TVRockは終了しておいてください。
3. 「③ 保存して予約一覧へ」でStudioの予約画面へ進みます。設定済みなら通常起動で予約画面が開きます。
4. 局・番組名・開始／終了日時・保存先を選び「予約する」を押します。開始は15秒以上先、録画時間は24時間以内です。
5. **StudioとPCを起動して待機してください。** スリープ・Studio完全終了中は新しい予約を開始できません。

×は通知領域への格納です。アイコンのダブルクリックで画面を開き、右クリックメニューで完全終了できます。

「録画を再生」で選択した予約のファイルを既定のプレーヤーへ渡します。「確認用録画」は受信テスト用の一覧です。設定の変更は「受信設定」から行います。

## 保存先

- アプリ：`%LOCALAPPDATA%\Programs\ZOOstudioPre`
- 予約・設定・ログ・確認用録画：`%LOCALAPPDATA%\ZOOstudioPre`
- 通常の録画：画面で指定。初期値はユーザーの「ビデオ」内の`ZOOstudio`です。

アンインストールしても設定・録画ファイル、TVRock・TVTest・Zooは削除しません。

## 検証範囲

開発環境のPXMLT5PE・TVTestで、TVRockのフォルダー・チューナー番号を渡さない約15秒の実予約録画を2回確認しました。主映像の表示と中間区間の映像・音声デコードも確認しています。

1回目は連続性警告と冒頭のデコード警告があり、2回目のTS検査は同期・受信エラー・スクランブル・連続性警告が0でした。**全録画の品質・長時間・複数局同時録画・他PC・他BonDriver・BS/CSは検証継続中です。** [詳しい検証範囲](VALIDATION.md)。

新規BonDriver導入・全周波数スキャン・地域コード自動設定は未実装です。実行ファイルは未署名です。
