# ZOOstudio 0.7.4（プレビュー版）

Studio単独で予約・録画・番組表を管理できます。

インテリジェント自動おすすめ予約は、録画履歴や取り消した番組などを参考に候補を選び、ユーザーの手動予約を優先します。詳細設定で件数を変更でき、「上限なし」も選べます。

空きチューナーで受信確認・番組表取得を並列処理します。録画を優先し、アイコンに録画中の件数を表示します。局名の保存・復元と画面整理も改善しました。

[インストーラーをダウンロード](https://github.com/newfrontierstudio/zoostudio/releases/tag/v0.7.4)

0.7.4では量子コンテキスト（密度行列・ボルン則・干渉・順序効果）をおすすめ予約に導入しました。アルゴリズムは `quantum-cognition-v1`。既定は量子70%・通常30%、詳細設定で変更できます。量子確率の数学をCPUで計算する試験的な機能で、実際の推薦精度の向上は未検証です。

取消した同じ放送は自動復活させず、次回以降の候補を頻度や予約状況から再評価します。上限は直近3日間の有効なおすすめ予約で集計し、取消・無効分を除外します。通常30分間隔、取消後約2分で再評価し、録画調整は方向・分・秒で入力できます。録画件数は通知領域に表示します。大きいタスクバーアイコンへの反映は改善中です。

更新前にStudioを完全終了してください。
